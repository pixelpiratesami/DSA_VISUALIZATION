# DSA_VISUALIZATION
# 📊 DSA Visualization

> An interactive desktop application to visualize Data Structures and Algorithms — built with Python and Tkinter to make learning DSA intuitive and engaging.

---

## 🎓 About the Project

This project was developed as our **2nd Year College Group Project** at **Pranveer Singh Institute of Technology, Kanpur** (Batch 2023–2027).

DSA Visualization is a Python-based desktop application that brings Data Structures and Algorithms to life through animated, step-by-step visual demonstrations. Instead of just reading about how algorithms work, you can **watch them happen** in real time — making it a powerful learning aid for students.

The application is built using **Python** and **Tkinter**, and features a unified menu that lets you launch any visualization from a single window.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:
- [Python 3.x](https://www.python.org/downloads/)
- `pip` (comes bundled with Python)
- Tkinter — usually included with Python by default. If not, install it:
  ```bash
  # On Ubuntu/Debian
  sudo apt-get install python3-tk

  # On Fedora
  sudo dnf install python3-tkinter
  ```

### Installation & Running

```bash
# 1. Clone the repository
git clone https://github.com/pixelpiratesami/DSA_VISUALIZATION.git

# 2. Navigate to the project directory
cd DSA_VISUALIZATION

# 3. Install required dependencies
pip install -r requirements.txt

# 4. Run the application
python DatastructureVisualizations.py
```

> Alternatively, you can also run it directly via:
> ```bash
> python3 PythonVisualizations/runAllVisualizationsMenu.py -w
> ```
